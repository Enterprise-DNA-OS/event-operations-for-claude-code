# draft-brief

Create an internal brief in drafts/. Inspect it, name its path and keep it unsent.

Use the single CLI:

`npm run events -- draft-brief`

Supported flags: --event. Flags take values as --name=value except --json and --dry-run. Read docs/cli.md and help for the complete interface.

State what the current records show, with names and dates. Drafts stay local. Never send, publish or take a payment.
