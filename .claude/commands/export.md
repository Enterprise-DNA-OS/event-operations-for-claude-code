# export

Write all seven record sets to a private exports/ path with --out. This is an interchange file, not a backup restore command.

Use the single CLI:

`npm run events -- export`

Supported flags: --out. Flags take values as --name=value except --json and --dry-run. Read docs/cli.md and help for the complete interface.

State what the current records show, with names and dates. Drafts stay local. Never send, publish or take a payment.
