# organisations

Compare recorded company attendance across events; do not infer business revenue.

Use the single CLI:

`npm run events -- organisations`

Supported flags: --json. Flags take values as --name=value except --json and --dry-run. Read docs/cli.md and help for the complete interface.

State what the current records show, with names and dates. Drafts stay local. Never send, publish or take a payment.
