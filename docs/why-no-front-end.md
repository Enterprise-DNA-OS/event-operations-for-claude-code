# Why the free base has no front end

An event operator can import registrations, allocate sessions, chase commitments and produce run sheets by asking an agent to use one CLI. The database holds the state. HTML files are read-only snapshots and printable paperwork, not an attendee application.

This does not provide public registration forms, mobile or offline check-in, drag-and-drop programme editing, payments, live chat or badge scanners. Those are real capabilities of an event platform. The free base is useful for operator-managed conferences and briefings whose registrations can be supplied as a file or entered by staff. It is not a complete Swoogo service clone.

Enterprise DNA scopes participant forms, connections and mobile workflows as part of a custom version. A managed Command Centre puts business views in its app shell. The local files here demonstrate reporting and printing; they are never deployed as a separate customer app.

Change brand.json to use your business name, logo path and approved colours. `npm run view` writes local views. `npm run docs` writes run sheets, speaker checklists, sponsor delivery records and internal attendance sheets. `/new-view` adds another read-only report. Neither command sends or publishes.
